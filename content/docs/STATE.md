Публикация автоматическая: пуш в `master` пересобирает сайт за пару минут
(`.github/workflows/pages.yml`). Корень сайта это `content/`, а не корень
репозитория. Workflow падает, если хоть на одной странице снят `noindex`.

`robots.txt` на Pages **не работает**: GitHub отдаёт его только с корня домена
`youpiter999.github.io`, а сайт лежит в подпапке. От поисковиков держит
`meta robots` на каждой странице, поэтому проверка в workflow не декорация.

## Сайт закрыт от поисковиков

`meta name="robots" content="noindex, nofollow"` на всех пяти страницах плюс
`Disallow: /` в `robots.txt`. Полуготовая страница в выдаче хуже её отсутствия.
**Перед запуском снимать оба разом**, иначе один останется и закроет сайт.

## Что готово

Пять страниц, все проверены живьём в браузере, ссылки и ресурсы отвечают 200
(17 уникальных, проверка прогоняется скриптом по всем страницам сразу).

- `index.html` — главная с кино-сценой
- `pink-slip.html` — визитёрский ВНЖ (доход из-за рубежа)
- `digital-nomad.html` — виза цифрового кочевника

- `rabota-i-semya.html` — работа и воссоединение семьи

### Кино-сцена

**Один непрерывный план на 18 секунд, склеек нет вообще.** Наезд 1.11 с
медленным сдвигом центра по одному исходнику (`SOURCE = 5`, побережье
с высоты), 540 кадров при 30 fps.

- Десктоп: `cyprus-descent.mp4` 960x400, 1.85 МБ
- Мобилка: `cyprus-descent-m.mp4` 600x750 (вертикальный кроп), 0.61 МБ
- Постеры `poster.avif` и `poster-m.avif` — первый кадр самого ролика,
  пишет их тот же `build-video.py`
- Собирает `scripts/build-video.py`, а НЕ `build-film.py`
- Прокрутка сцену не трогает: ни закрепления, ни перемотки. Видео идёт
  по кругу, петля бесшовная по построению (движение туда-обратно по
  косинусу, на развороте скорость нулевая)
- Семь текстовых плашек сменяются по доле длительности ролика (`data-at`),
  а не по прокрутке

**Почему так, а не иначе (три захода).** Секвенция 17 картинок при 12 fps
читалась рывками. Уплотнение до 30 fps не помогло. Укрупнение планов
(9 вместо 17, переход длиннее показа) сбило пик, но не суть. Замер по
готовым файлам объяснил всё: дёрганье давал **монтаж**, а не частота
кадров. У версии из девяти планов межкадровая разница 3.07 в медиане и до
9.07 на склейках; у одного плана 1.60 и максимум 3.01 без единого пика.
Девять смен содержания остаются девятью рывками, сколько их ни растягивай.

Замер повторяется так:

```bash
ffmpeg -v error -i cyprus-descent.mp4 \
  -vf "tblend=all_mode=difference,signalstats,metadata=print:key=lavfi.signalstats.YAVG:file=-" \
  -f null - | grep -o 'YAVG=[0-9.]*'
```

От старой секвенции в репозитории оставлены только кадры героев подстраниц
`f_060`, `f_100`, `f_120`, `f_130` (и `f_001`, который постером больше не
служит). Остальные 173 удалены. `build-film.py` их пересоздаст, если
понадобится, но видео он больше не пишет: его `encode_preview` собирал
12 fps в тот же файл и вернул бы рывки.

Постером стоял `frames/f_001.avif` — первый кадр старой секвенции, то есть
облака, тогда как ролик начинается с побережья. До первого кадра на экране
стояла одна картинка, а с началом воспроизведения подменялась другой: скачок
содержания на старте, который читается как рывок ещё до того, как что-то
поедет. Теперь постер выдаёт `build-video.py` из того же кадра, разойтись
они не могут.

### Воспроизведение

Видео играет само по кругу и ничего не ждёт: прокрутка его не касается,
страница листается свободно с первой секунды. Телефон может отказать в
автозапуске (энергосбережение iOS, экономия трафика Android) — попытка
повторяется при первом касании. За экраном видео ставится на паузу через
`IntersectionObserver`, при `prefers-reduced-motion` остаётся один постер.

### Лист проверки пакета

Единственный визуальный объект на сайте, который не выдан генератором,
а свёрстан: бланк с отметками, нарисованными путями, росчерком под строкой
и заметкой на полях. На главной стоит рядом с этапами работы, на подстраницах
заменил простой список документов, строки берутся из того же `docs` в
`build-pages.py`, отмеченную строку задаёт поле `mark`, заметку `note`.

Печати и штампа нет намеренно: имитация официальной отметки на сайте про
легальный статус читалась бы как подделка документа.

### Появление блоков при скролле

`assets/js/reveal.js`. Сдержанно: 14px подъёма и прозрачность, волна по
соседям внутри группы, одноразово. Скрытое состояние задаётся стилями до
первой отрисовки, иначе страница успевает мелькнуть готовой. Встроенный
скрипт в `<head>` ставит класс `js-reveal` и снимает его по таймауту, если
`reveal.js` не доехал: страница без анимации нормальна, страница из
невидимого текста нет.

Список селекторов продублирован в CSS и в JS, и в CSS он завёрнут в `:where`.
Без этого `.js-reveal .reqs > div` весит больше, чем `.js-reveal .in`,
и карточки не могут проявиться в принципе.

### Проверки, встроенные в сборку

Скрипты падают с ошибкой, а не молча пропускают:
- длинное тире в тексте (`build-pages.py`)
- видимая плашка-заглушка в разметке (`build-pages.py`)
- служебные фразы в интерфейсе (`build-pages.py`, дублируется в `patch-round2.py`)
- несуществующий кадр героя (`build-pages.py`)
- нечётный размер кадра, при котором не собирается видео (`build-film.py`)

`patch-round2.py` больше не обязателен: его правки сложены обратно в шаблон
`build-pages.py`. До этого пересборка страниц возвращала два бага сразу.

## Ограничения окружения

- **Видеогенерации нет.** kie.ai не подключён (ключ не был предоставлен), Gemini
  упирается в исчерпанные кредиты аккаунта, у Pollinations видео требует ключ.
- **Картинки бесплатно:** `~/.claude/scripts/gen-image.ps1` (Pollinations, без ключа,
  потолок 1024px).
- **ffmpeg** не читает AVIF-секвенцию и спотыкается о кириллицу в пути. Обход через
  временные PNG уже встроен в `build-film.py`.

## Пересборка с нуля

```bash
python scripts/gen-film-sources.py   # 17 исходников, около 10 минут, последовательно
python scripts/build-video.py        # оба видео сцены при 30 fps
python scripts/build-film.py         # кадры-картинки: постер и герои подстраниц
python scripts/build-pages.py        # 4 подстраницы из шаблона
python scripts/fetch-assets.py       # шрифты и GSAP локально
```

Порядок важен: `build-film.py` требует готовых исходников. `patch-index.py`
и `patch-round2.py` нужны только для истории, подстраницы теперь выходят
из `build-pages.py` уже правильными.
