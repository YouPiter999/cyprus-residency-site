# Состояние проекта на 26.07.2026

Сайт про получение ВНЖ **Республики Кипр** (южный, ЕС) для клиента по имени Егор,
друга владельца. С edhab.com (Северный Кипр, студенческий ВНЖ) не пересекается,
SEO не каннибализирует.

## Как запустить и посмотреть

```bash
cd "C:\Users\Сергей\Downloads\егор-сайт\content"
python -m http.server 8899 --bind 127.0.0.1
# http://127.0.0.1:8899/index.html
```

Открывать через сервер, а не файлом: секвенция кадров грузится по сети.

## Что готово

Пять страниц, все проверены живьём в браузере, ссылки и ресурсы отвечают 200.

- `index.html` — главная с кино-сценой
- `pink-slip.html` — визитёрский ВНЖ (доход из-за рубежа)
- `digital-nomad.html` — виза цифрового кочевника
- `pmzh-investicii.html` — ПМЖ по инвестициям
- `rabota-i-semya.html` — работа и воссоединение семьи

### Кино-сцена

Непрерывный полёт с облаков к морю: 17 сгенерированных исходников, из них
программно построено 134 кадра при 12 fps. Canvas + GSAP ScrollTrigger, pin и scrub.

- Десктоп: 134 кадра AVIF 960x400, 2.37 МБ
- Мобилка: 45 кадров AVIF 600x750 (вертикальный кроп), 0.66 МБ
- Закрепление: 320vh десктоп, 260vh мобилка
- Семь текстовых блоков на дискретных порогах прогресса
- Проверено: 10 уникальных кадров на 10 точках, зависаний нет

Иллюзия непрерывности держится на: движение только на приближение, неравномерная
раскадровка (равные планы дают метроном), кроссфейд 3 кадра со smoothstep, смаз на
стыках, единая цветокоррекция под палитру сайта.

### Проверки, встроенные в сборку

Скрипты падают с ошибкой, а не молча пропускают:
- длинное тире в тексте (`build-pages.py`)
- видимая плашка-заглушка в разметке (`build-pages.py`)
- служебные фразы и имя заказчика в интерфейсе (`patch-round2.py`)
- нечётный размер кадра, при котором не собирается видео (`build-film.py`)

## Ограничения окружения

- **Видеогенерации нет.** kie.ai не подключён (ключ не был предоставлен), Gemini
  упирается в исчерпанные кредиты аккаунта, у Pollinations видео требует ключ.
- **Картинки бесплатно:** `~/.claude/scripts/gen-image.ps1` (Pollinations, без ключа,
  потолок 1024px).
- **ffmpeg** не читает AVIF-секвенцию и спотыкается о кириллицу в пути. Обход через
  временные PNG уже встроен в `build-film.py`.

## Пересборка с нуля

```bash
python scripts/gen-film-sources.py   # 17 исходников, около 10 минут, последовательно
python scripts/build-film.py         # кадры + предпросмотр mp4
python scripts/build-pages.py        # 4 подстраницы из шаблона
python scripts/fetch-assets.py       # шрифты и GSAP локально
```

Порядок важен: `build-film.py` требует готовых исходников.
